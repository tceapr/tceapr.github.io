# Ban Boring Words

Two-level prototype for grades 3-8.

Open `index.html` in a browser to review the activity. It is a single self-contained page with embedded HTML, CSS, and JavaScript, so it can later be published with GitHub Pages by placing this folder in a repository and serving `index.html`.

This version includes:

- Level 1 for grades 3-5
- Level 2 for grades 6-8
- Find a Better Word generator
- Word Choice Challenge activity
- 12 boring words per level
- 30 alternatives per word per level
- Level 1 generator shows 3 alternatives at a time
- Level 2 generator shows 5 alternatives at a time
- 12 sentence-based challenge rounds per level
- Level 1 challenges use 4 choices each
- Level 2 challenges use 5 choices each
- Custom improved sentences for challenge feedback
- "Give Me 3 More", "Give Me 5 More", "Choose Another Word", "Surprise Me", "Play Again", "Back to Home", and "Change Level" flows

No accounts, external links, timers, scores, ads, frameworks, or external assets are included.
